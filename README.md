# CustomerCrudApp

A C# application for managing customer data with CRUD (Create, Read, Update, Delete) operations.

## Overview

This project provides a comprehensive solution for customer relationship management with full database integration and business logic.

## Features

- **Create** - Add new customers to the system
- **Read** - Retrieve customer information
- **Update** - Modify existing customer data
- **Delete** - Remove customers from the system

## Technologies

- **Language**: C#
- **.NET Framework**: Built with C# for robust, enterprise-grade development

## Getting Started

### Prerequisites

- .NET Framework or .NET Core installed
- Visual Studio or Visual Studio Code recommended

### Installation

1. Clone the repository
```bash
git clone https://github.com/liewvk/CustomerCrudApp.git
```

2. Navigate to the project directory
```bash
cd CustomerCrudApp
```

3. Build the project
```bash
dotnet build
```

4. Run the application
```bash
dotnet run
```
